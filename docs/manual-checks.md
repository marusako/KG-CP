# 手で確かめること（チェックリスト）

自動テスト（`npm test`）では確かめられない、ブラウザや実機での確認をまとめる。
確認したら `[ ]` を `[x]` にする。気になったことは各節の「メモ」に書く。
新しい段階を作ったら、その確認をここに足す。

## 準備

- 公開版: https://marusako.github.io/KG-CP/
- ローカル版: `npm run dev` を実行し、表示された URL を開く（止めるときは `Ctrl + C`）
- 使うデバイス: キーボード、パッド（あれば Xbox 系と PlayStation 系の両方）
- 初期のキー: 方向 WASD、パンチ U I O（LP MP HP）、キック J K L（LK MK HK）

### 1. キー入力と入力履歴（第1段階・不具合の修正）

- [ ] キーを押すと、左の「入力履歴」に方向（矢印）・ボタン・フレーム数が新しい順で流れる

- [ ] パッドの十字キーと左スティックで方向が入る。パッドとキーボードを同時に使っても両方効く

### 2. コマンド練習（第1段階・変更 1・変更 2）

- [ ] 右の一覧の 8 つのコマンドが、それぞれ入力して「成立！」になる
  - 236P / 214P / 623P / 41236P / 63214P / [4]6P（4 を約 0.7 秒溜めて 6+P）/ [2]8K / 360P
- [ ] 成立したとき、モーションとボタン遅れのフレーム数が出る
- [ ] 失敗したとき、理由が日本語で出る

  - 最初の手が入っていない（例: 36P）
  - モーションが遅すぎる（ゆっくり回す）
  - ボタンが遅すぎる（236 のあと 6 を長く押してから P）
  - 溜めが足りない（[4]6P で溜めを短く）
  - 回転が足りない（360P で途中まで）
- [ ] 236 の最後の 6 を押し続けてから P を押すと、「モーションが遅い」ではなく「ボタンが遅い」になる
- [ ] 「直近の成功率」が増えていく
- [ ] 判定の甘さ・厳しさの感触（猶予は仮の値なので、きつい・ゆるいと感じたら書く）

### 3. コンボトライアル（第2段階）

- [ ] 上のタブで「コンボトライアル」に切り替えられる
- [ ] サンプル 3 つが一覧に出て、それぞれ完走できる（「完走！」が出る）
- [ ] 手の列で、次に入れる手が強調され、成功した手は緑で `+12F` のように出る
- [ ] 失敗の表示が出る
  - 早い（「あと ◯F 遅く」）: 窓より早く押す
  - 遅い（「窓は ◯〜◯F」）: 窓より遅く押す
  - 違う入力: 2LP の手で 5LP を押す
- [ ] 挑戦回数・完走回数・完走率が正しく増える
- [ ] テキスト欄に JSON を打っている間、打った文字がゲームの入力にならない（回数が増えない）
- [ ] 「JSON に書き出す」でレシピが JSON になって出る
- [ ] 書き出した JSON の id と name を変えて「JSON を読み込む」と、一覧に増える
- [ ] 壊れた JSON を読み込むと、日本語のエラーが出る
- [ ] サンプルと同じ id のレシピを読み込むとエラーになる
- [ ] ページを再読み込みしても、読み込んだレシピが残っている
- [ ] 別のブラウザタブに切り替えて戻ると「処理が止まったため、この挑戦は無効です」が出る（挑戦していなくても出る。既知の挙動）

### 5. キーコンフィグ（第4段階・変更 1）

操作中のデバイスと図:
- [ ] 「操作中: キーボード」と出る。パッドに触ると「操作中: （パッドの名前）（PlayStation 式 / Xbox 式）」に変わり、図もパッドに切り替わる
- [ ] パッドをつないで最初に押したボタンで、もう切り替わる
- [ ] 「キーボード」「パッド」のタブで手動で切り替えると、自動では切り替わらなくなる。「自動」で元に戻る
- [ ] パッドのボタン名が、パッドに合った表記（A/B/X/Y か ×/○/□/△）になる。分からないパッドは番号になり、文字が重ならない
- [ ] 図の各ボタン・キーに、割り当てた操作（LP など）が書かれている
- [ ] 押したボタン・キーが図で光る。左スティックを倒すと点が動く
- [ ] 「いまの入力（キーボード / パッド）: ↘ + LP」のように、図のデバイスの入力が出る
- [ ] キーボードとパッドで図を切り替えても、画面の配置が崩れない
- [ ] キーボードの図の文字が読める大きさ

まとめて設定:
- [ ] 「まとめて設定（キーボード）」で、上 → 下 → 左 → 右 → LP …の順に聞かれ、押したキーが割り当たる
- [ ] 「まとめて設定（パッド）」で、LP〜HK の 6 つが順に聞かれる
- [ ] 同じキー・ボタンを 2 回使うと「すでに ◯◯ に使っています」が出て、先に進まない
- [ ] パッドで十字キーを押すと、受け付けずに理由が出る
- [ ] Esc か「取り消し」で、何も変わらずに終わる
- [ ] キーを長押ししても、すぐにエラーが出ない
- [ ] 設定中に押した入力で、コマンド練習やトライアルが進まない
- [ ] 設定し終わった直後に押したキーが、ちゃんと効く（1 回目が捨てられない）
- [ ] 最後のボタンを押したまま設定を終えても、そのボタンが「押した」扱いでゲームに入らない（離して押し直すと入る）

個別に直す:
- [ ] 一覧の操作（例: 「LP: U」）をクリックしてキーかボタンを押すと、その操作だけ変わる
- [ ] ほかの操作が使っているキーを選ぶと、入れ替わって「◯◯と入れ替えました」と出る
- [ ] 入力待ちで Esc を押すと、何も変わらずに終わる

そのほか:
- [ ] ページを再読み込みしても、割り当てが残っている
- [ ] Space や Enter を割り当てても、プレイ中にボタンが勝手に押されたり、チェックボックスが切り替わったりしない
- [ ] パッドを抜くと「操作中」がキーボードに戻る

### 残っている提案（直すか決める）

- [ ] 設定を始めてから 1 フレーム未満で終えると、前から押していた入力が漏れることがある（ほぼ起きない）
- [ ] ウィンドウがとても狭いと、キーボードの図の文字が 12px を下回る
- [ ] まとめて設定の途中も、スティックの点が動く
- [ ] 別のタブから戻ると、挑戦していなくても「無効」が出る（挑戦の途中だけ出すようにする案）
- [ ] 止まったとき、コマンド練習の入力履歴がつながって判定される（止まったら履歴を空にする案）
- [ ] 止まった回の数値が計測に混ざり、平均 Hz がずれる
- [ ] パッドを 2 台つなぐと、パッドの更新間隔が短く出る
- [ ] 1 フレームより短いタップ・同時押しのゴーストなど、キーボード本体の問題が疑われるか

- [ ] デスクトップ版でも、ここにある 1〜5 の確認がすべて通ること（作ったら、この節にデスクトップ版の確認を足す）
